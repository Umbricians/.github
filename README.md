# Umbricians · .github

Community health files and the organization profile for [Umbricians](https://www.umbricians.com) — an Umbraco agency and certified Umbraco Gold Partner.

The Umbricians GitHub organization is where we publish our **open source projects**: Umbraco packages, tools, and utilities we've built and want to share with the community.

- The org profile shown at [github.com/Umbricians](https://github.com/Umbricians) lives in [`profile/README.md`](profile/README.md).
- Default community health files (issue templates, contributing guidelines, code of conduct, etc.) added here apply to all Umbricians repositories that don't define their own.
